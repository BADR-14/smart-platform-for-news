# Smart Platform for News — تطبيق الموبايل (Flutter)

تطبيق الزائر والمستخدم والشركة: تصفّح المحاضرات والمعارض والفعاليات والدورات، التفاعل معها،
متابعة الشركات، توثيق الحساب، والنشر للحسابات الموثّقة.

> لوحة الشركة (المحفظة، الباقات، المنشورات المميزة) ولوحة الأدمن موجودتان في مشروع الويب `../web`.

## المتطلبات

- Flutter 3.35 أو أحدث (Dart 3.9+)
- الباك-إند يعمل على الحاسوب: `php artisan serve --host=0.0.0.0 --port=8000`

## التشغيل

```bash
flutter pub get
```

```bash
flutter run
```

العنوان الافتراضي للـ API هو `http://10.0.2.2:8000/api` (يعمل على **محاكي أندرويد**؛ `10.0.2.2` هو الحاسوب المضيف).

على **جهاز حقيقي** مرّر عنوان الحاسوب على الشبكة المحلية:

```bash
flutter run --dart-define=API_URL=http://192.168.1.5:8000/api
```

| المتغير (`--dart-define`) | الوصف |
|---|---|
| `API_URL` | عنوان الـ API |
| `GOOGLE_SERVER_CLIENT_ID` | الـ Web Client ID من Google Cloud. إن لم يُمرَّر يختفي زر "المتابعة عبر Google" |

## المعمارية

**Feature-first** مع ثلاث طبقات داخل كل ميزة، و **GetX** لإدارة الحالة والتنقل وحقن الاعتماديات.

```
lib/
├── main.dart                 نقطة البداية: تهيئة الجلسة ثم تشغيل التطبيق
├── app/
│   ├── app.dart              GetMaterialApp (الثيم، اللغة العربية، RTL)
│   ├── routes.dart           أسماء المسارات
│   ├── app_pages.dart        كل مسار مع الـ Binding الخاص به
│   └── bindings/             الاعتماديات الدائمة (ApiClient، المستودعات، الخدمات)
├── core/                     ما تتشاركه كل الميزات
│   ├── config/               إعدادات وقت البناء (--dart-define)
│   ├── network/              ApiClient (Dio) + ApiException + Paginated
│   ├── session/              SessionService: حالة الدخول (مصدر الحقيقة الوحيد)
│   ├── storage/              حفظ التوكن مشفّراً (Keystore / Keychain)
│   ├── controllers/          PagedController: أساس كل القوائم المقسّمة لصفحات
│   ├── services/             GeocodingService (OpenStreetMap)
│   ├── theme/                الألوان والثيم (من الشعار: كحلي + برتقالي)
│   ├── utils/                قراءة JSON الآمنة، التنسيق، التحقق، الرسائل، التنقل
│   └── widgets/              عناصر الواجهة الموحّدة (زر، حقل، قائمة مقسّمة، حالات ...)
└── features/
    ├── auth/                 دخول، تسجيل، تأكيد البريد (OTP)، استعادة كلمة المرور، Google
    ├── posts/                الرئيسية، التفاصيل، التعليقات، التقييم، إنشاء/تعديل، منشوراتي، المحفوظات
    ├── companies/            قائمة الشركات، صفحة الشركة، المتابعة
    ├── profile/              حسابي، تعديل الملف، الملف العام لحساب آخر، تقييماتي
    ├── verification/         حالة التوثيق، طلب توثيق مستخدم، طلب إنشاء شركة
    ├── notifications/        الإشعارات وعدّاد غير المقروء
    ├── settings/             كلمة المرور، إعدادات الإشعارات، حذف الحساب
    ├── shell/                الشريط السفلي وزر إنشاء منشور
    ├── splash/               شاشة البداية (استعادة الجلسة)
    └── shared/               نماذج مشتركة (Account, Author, Category)
```

داخل كل ميزة:

| الطبقة | المحتوى | تعتمد على |
|---|---|---|
| `domain/` | النماذج (immutable) + **واجهة** المستودع المجردة | لا شيء |
| `data/` | تطبيق المستودع عبر `ApiClient` | domain |
| `presentation/` | المتحكمات (GetX) + الشاشات + الـ widgets | domain فقط |

### أنماط التصميم المستخدمة

| النمط | أين | لماذا |
|---|---|---|
| **Repository** | `domain/*_repository.dart` + `data/*_repository_impl.dart` | المتحكم لا يعرف Dio ولا شكل الـ JSON؛ يمكن استبدال المصدر في الاختبارات |
| **Dependency Injection** | `InitialBinding` + `app_pages.dart` | كل صنف يستلم اعتمادياته عبر الباني، ولا ينشئها بنفسه |
| **Template Method** | `PagedController.fetchPage` | منطق التقسيم لصفحات مكتوب مرة واحدة، والوارث يطبّق جلب الصفحة فقط |
| **Observer** | `PostActions.updated/deleted`، `CompanyFollowService.updated` | المنشور نفسه يظهر في عدة شاشات؛ تغييره في واحدة يحدّث الباقي دون أن تعرف الشاشات عن بعضها |
| **Mixin** | `PostSyncMixin` | يضيف مزامنة المنشورات لأي متحكم يعرضها |
| **Adapter** | `ApiClient` | يحوّل أخطاء Dio إلى `ApiException` برسالة عربية ورمز ثابت وأخطاء حقول |

### قواعد متّبعة

- لا يوجد لون أو عنوان API مكتوب داخل الشاشات: الألوان من `AppColors` والعنوان من `AppConfig`.
- النماذج غير قابلة للتعديل؛ أي تغيير ينتج نسخة جديدة عبر `copyWith`.
- التحقق المحلي (`Validators`) مطابق لقواعد الباك-إند، وأخطاء 422 تُعرض تحت الحقل نفسه.
- الزائر يتصفح بحرية؛ كل إجراء يحتاج حساباً يمر عبر `SessionService.requireLogin`.
- النشر للحسابات الموثّقة فقط (`Account.canPublish`)، والباك-إند يفرض القاعدة نفسها.
- إغلاق الصفحات عبر `AppNav.back` وليس `Get.back` (الأخيرة تغلق الرسالة الظاهرة بدل الصفحة).

## ملاحظات

- **الإشعارات الفورية (Push)**: الباك-إند جاهز لإرسالها عبر FCM، لكن ربط التطبيق بـ Firebase
  يحتاج مشروع Firebase وملف `google-services.json`، وهو غير مضاف. الإشعارات تظهر داخل التطبيق
  (تبويب الإشعارات) وتتحدث عند فتحه أو السحب للتحديث.
- **وثائق التوثيق** تُرفع كصور (كاميرا أو معرض). رفع PDF متاح من الـ API لكن ليس من التطبيق.
- `android:usesCleartextTraffic="true"` في `AndroidManifest.xml` مخصص للتطوير المحلي عبر http؛ يُحذف عند النشر على https.
- الخريطة تستخدم OpenStreetMap و Nominatim بدون مفتاح، وهي مناسبة لمشروع تخرج لا لحمل إنتاجي عالٍ.
